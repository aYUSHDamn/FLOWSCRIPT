FlowScript Recovery Synthesis Model

1. Finite-State Discrete Model

The system state $S \in \mathcal{S}$ is modeled as a mapping $D_{\text{controllable}} \to \{\text{ON}, \text{OFF}\}$. Actuations are discrete state transitions $\delta(S, a) \to S'$ with instantaneous simulated effects.

2. Safety-Constrained Search ($\mathcal{I}$)

Every candidate transition is validated against global safety contracts. If an invariant evaluates to false in intermediate state $S'$, the transition is pruned immediately, guaranteeing safety-by-construction.

3. Fail-Closed Safety Property

If no action sequence reaches the target predicate within $k = \text{max\_steps}$, or if invariants eliminate all paths, the compiler aborts compilation. No partial or unsafe plan is ever emitted.

Simulation vs. Physical Actuation:

This prototype simulates ideal discrete binary devices. Real-world physical cyber-physical deployment requires accounting for actuator slew rates, sensor noise, network packet loss, and continuous physics.
